01Harness 是什么：模型只是发动机

不少产品能调用同一批模型，用起来却差很多。差别主要在模型外面。

大模型本身只负责生成后续内容。网页聊天框里的它看不见你的文件系统，改不了代码，也跑不了命令。要让它在真实仓库里干活，还得配眼睛、双手、记性和刹车：

眼睛

读文件、搜代码、看仓库结构的工具，让它"看得见"你的工程。

双手

改文件、执行 shell 命令、跑测试、操作 git 的工具调用。

记性与工作方法

上下文管理：任务长了会压缩摘要、维护项目记忆，不在第 40 分钟忘了第 4 分钟的目标。

刹车与规矩

权限控制：删文件、git push、改配置这类危险动作必须先过你确认，敏感目录直接禁入。

术语卡：Harness Agent

以 LLM 为引擎，配上工具调用、上下文管理、权限控制和任务循环的执行框架，让模型能在真实仓库里自主完成"理解 → 修改 → 验证 → 修正"的多步任务。英文 harness 本义是"马具"，马是模型，缰绳、马鞍就是 harness。你听到的 Claude Code、Cursor、Copilot、ZCode，本质都是 harness + 各家模型的组合。

选 Agent 工具，核心是选 harness：上下文怎么组织、工具怎么设计、权限怎么管、失败后怎么重试。同一个模型接上不同客户端，表现可以差很多。上下文喂错会答非所问，权限太松会闯祸，没有验证循环就容易改一行错一行。

02先分类：常见的五类产品形态

名字可以很多。按"AI 在哪里干活、人怎么参与"看，市面上常见形态大致是五种。

类别工作位置与参与方式适合的活主要风险
IDE 补全插件编辑器内贴着你写，边写边按 Tab手速、样板、重复模式价值容易被低估
AI 原生 IDE整个编辑器围绕 AI，对话 + Agent 面板中大型改动、跨文件重构上下文整仓上云
终端 CLI Agent终端里跑，直接操作仓库，逐步确认全仓任务、批量改造、CI 集成权限大，必须配沙箱
云端异步 Agent厂商云上开机器跑，派任务回头收 PR机械化改造、依赖升级代码上传第三方；账单失控
审查 / 运维 Bot挂在 PR 或流水线上，看结论定采纳代码审查、安全扫描只能是辅助，不能替代 Approver

再叠一层"部署形态"，它决定能不能给敏感项目用：公网 SaaS（上下文出网）→ 企业版 SaaS 零留存条款（出网但受合同约束）→ 自托管 Runner（模型在云、执行在内网）→ 完全私有化（数据不出内网）。

先问这个项目的数据能不能出网，再比功能强弱。敏感级没定，后面的对比很容易空转。

03三个问题定方向

看产品页之前，先回答这三个问题。

1

这个团队的代码能不能出公司网络？

不能 → 只剩一条路：私有化客户端 + 本地/私域模型（国产专属版 / 开源自托管 Harness）。这个问题不解决，后面都不用看。

2

瓶颈是打字手速，还是任务吞吐？

手速 → IDE 补全 / AI 原生 IDE，成本低上手快。吞吐 → CLI Agent / 云端异步 Agent，但必须配套沙箱、审批与限额。

3

工程化配套成熟吗？（测试、CI、评审制度）

不成熟 → 先用补全层、人重把关，别急着上"自动改全仓"；成熟 → 放开 Agent 模式，用 CI 兜住质量。

不少团队最后会配成这样：IDE 补全加 CLI Agent 做日常，全仓挂审查 Bot，云端异步只给一两个团队试点。补全管手速，Agent 管任务吞吐，Bot 减轻人审压力。它们更像组合件，不是三选一。

04评估标准：八项能力 + 采购三问

先把标准写下来，再看具体产品。下面八条缺了哪条，日常都会别扭。

1

完整的 Agent Loop：读 → 改 → 跑 → 看 → 再改

改完代码必须自己跑测试或编译、自己读报错、自己接着修，循环到通过为止。只会"输出一段代码让你自己粘"的工具还停留在对话时代。

2

上下文工程：大仓库、长任务不迷路

真实任务动辄读几十个文件、跑几小时。好的 harness 会做压缩摘要、维护项目记忆（如 AGENTS.md）、建代码导航，让它在第三个小时还记得第三分钟的目标。

3

权限与安全：刹得住，才敢放手

agent 能删文件能推代码，威力大风险也大。看三样：确认门禁、命令沙箱、敏感文件保护（.env、密钥禁读禁改）。检验方式很朴素：不敢让它碰生产配置，就是刹车不过关。

4

扩展体系：MCP、Skills、Hooks

MCP 是连接外部系统的开放标准，接上内部数据库、工单系统，agent 干的就不是"写通用代码"而是"干你们的活"；Skills 把固定流程沉淀成可复用技能；Hooks 在关键节点强制执行规矩。没有扩展体系的 agent，天花板就是出厂默认。

5

模型开放性（BYOK）：能换发动机

模型排名月月在变，今天的冠军不一定是明天的。好 harness 不把你锁死在一家模型上：支持配置多供应商，日常用便宜模型、关键任务上旗舰。

6

自动化与并行：人不在，活照干

后台任务、定时任务、多 Agent 并行、远程唤起（下班前在 IM 里丢任务，地铁上收结果）。这是 harness agent 相对补全类工具的代差优势。

7

团队知识沉淀：新 Agent 直接继承老规矩

项目规范写进 AGENTS.md 放进仓库，所有人的 agent 打开项目自动继承同一套规矩。团队统一工具的真正收益在这里：行为从"随缘"变成"有章可循"。

8

低门槛：5 分钟能装好，报错看得懂

中文界面、图形化安装、清晰的额度提示，这些不起眼的因素常常决定一个工具在团队里的真实存活率。

企业采购侧再单独问三件事

  • 数据流向与部署形态：代码是否出网？留存与训练条款？能否私有化（对照第 02 节的四档）？
  • 企业治理：SSO/SCIM、席位与额度管理、审计日志、仓库/模型/MCP 访问控制，大团队必问，小团队可延后。
  • 集成面：覆盖你们的 IDE、终端、CI、代码平台和 IM 吗？缺一项就得有人手工补桥。

05主要选手逐个看

八位选手，信息截至 2026-10-16。采购前以官网实时页面为准。

ZCode

智谱（GLM）· GLM-5.3 官方 Harness本文主推

智谱推出的桌面端编程 Agent 客户端（Windows / macOS / Linux 全平台，含 ARM 版），深度适配 GLM-5.3 / GLM-5.3-Flash，中文原生界面。形态上不是命令行工具，而是完整的图形工作台：对话区、终端、Git 面板、任务管理一屏俱全。

  • 开箱即用的中文体验：中文界面与文档、人民币直购，新用户体验套餐（首次使用起 5 天内每天 800 万 token，GLM-5.3 300 万 + GLM-5.3-Flash 500 万）足够在真实项目里把 Agent 跑顺再决定订阅，团队推广摩擦最小。
  • 长程任务（Goal）：专为几小时级目标设计，持续规划-执行-验证，带进度分解与 token 统计。
  • 远程唤起：微信 / 飞书 / Telegram 给 Bot 发消息即可远程启动任务。
  • 扩展体系齐全：MCP、Skills（SKILL.md 开放格式）、插件市场、Hooks、自定义命令。
  • 一份订阅，多工具共享：GLM Coding Plan 的额度可在 ZCode、Claude Code、Codex、OpenCode 等 20+ 官方支持的工具间通用，起步用它，横向对比其他 harness 不必重新付费。
  • 客户端不开源，深度定制只能走扩展点。
  • 插件与技能生态比 Claude 系年轻，社区沉淀还在积累。

适合：想装好就用、中文无障碍、价格友好、还能接内部系统的团队。推荐理由见第 09 节。

Claude Code

Anthropic · 能力标杆对照组

终端 Agent 的开创者，形态最全：CLI、VS Code / JetBrains 插件、桌面、移动端、GitHub Actions / GitLab CI、Slack 集成。工程实践文档是品类里写得最完整的，可以直接抄。

  • 编码能力第一梯队，生态存量最大，出问题最容易搜到答案。
  • 企业管控完整：受管设置（managed-settings.json）优先级高于用户配置，可锁模型、登录方式与 MCP 白名单；商业版不用代码训练、标准留存 30 天。
  • OS 级沙箱实践最好：权限弹窗减少 84%。
  • 价格偏高且企业定价不公开（团队席参考 $25 / $125 每月）；大陆无直连服务，海外账号、支付与数据出境合规要公司层面过。
  • 顶级档 Mythos 有资质与出口管制门槛，2026 年出过临时访问中断。

适合：有海外订阅条件、追求能力上限、需要标杆做对照的团队。

Cursor

2026-08 并入 SpaceX（与 xAI 同属马斯克系）· 一体化平台

AI 原生 IDE 加云端 Agent 平台：IDE + CLI + 云任务（Cloud Agents、Projects）+ 审查（Bugbot / Security Review）+ 变更监控（Rollouts）。多模型可选：Grok、Claude、Gemini、自研 Composer。

  • 企业治理项最全：SSO/SCIM、审计日志、自管密钥（CMEK）、数据驻留、PrivateLink。
  • 支持自托管执行机器（Team Pools），工具执行留在自有网络。
  • Plus $8/月（仅 Grok 模型）；编程主力更接近 Premium $30/月，Teams $30/席起。
  • Agent 主循环仍在厂商云上，整仓上下文会出网，自托管不等于私有化。
  • 并入 SpaceX 后与 xAI/Grok 深度绑定（同属马斯克系），供应商风险要写进合同条款。

适合：需要 IDE 手感加云端异步任务、并能接受上下文出网的团队。Plus 档偏社交/轻量，日常编码建议从 Premium 看起。

GitHub Copilot

GitHub · 平台内建治理即产品

治理"产品即合规"：以下门禁全是产品默认行为，不需要自己配。

  • 草稿 PR 必须人工评审并合并；代理不能 approve/merge；代理署名的 PR 还需额外一次人工批准。
  • 企业版内建 CodeQL、依赖扫描、secret scanning；审计日志保留 180 天。
  • Business $19 / Enterprise $39 每人每月，代码在 GitHub 上的团队迁移成本最低。
  • GitHub Enterprise Server 上可用，但模型推理仍经 GitHub/Azure 云端处理，无真正私有化选项。
  • 审计日志不含客户端本地会话，取证时要另想办法。

适合：代码在 GitHub 云上、要"开箱即用合规"的组织。

Codex

OpenAI · 开源 CLI + 多形态

CLI 完全开源（Rust，Apache-2.0，GitHub 10 万+ star，可审计可自建），另有 VS Code / JetBrains 扩展、桌面与云端任务；CLI 与 ChatGPT 桌面端、VS Code 扩展共享同一份 ~/.codex/config.toml，一次配置三处可用。

  • 过公司安全审查最省事：代码可审计、可自建、可改造。
  • BYOK 最彻底：可接任意 OpenAI 兼容端点（OpenRouter、Azure、DeepSeek 等），包括用 GLM Coding Plan 的额度驱动它。
  • ChatGPT 订阅附带，多形态切换（Plus $20/月 即可用）。
  • 与 Claude Code 同样的国内可用性门槛：官方服务需海外账号与支付。
  • 终端为中心的极客风，扩展生态不如 Claude 系；企业治理细节逐项确认。

适合：喜欢终端工作流、看重开源可审计、想把 agent 接到自选模型端点上的工程师。

Antigravity

Google · Gemini CLI 的继任者

2026-06 起接替 Gemini CLI 承接免费层与 Google One 用户（原 CLI 仍开源 Apache-2.0）。桌面、CLI、多 IDE 扩展（含 Zed、Xcode）形态齐全。

  • 终端沙箱默认开启，安全团队加分项。
  • 支持并发后台子代理、git worktree 隔离、Hooks。
  • 产品线正在整合：Code Assist 新订阅已停售、CLI 更替中，采购路径先找厂商确认；默认旗舰模型仅高档订阅可用。

适合：已使用 Google Cloud / Workspace 的团队；看重"默认安全"的场景。

CodeBuddy

腾讯 · 国产客户端代表私有化主力

国产客户端以 CodeBuddy 为代表。插件 + 自研 IDE + CLI 全形态（业内首批），企业专享版专有云（100 席起），支持自定义模型（含 Ollama 本地模型），体验版免费（每月 500 积分）。同类还有字节 Trae、阿里通义灵码 / Qoder、百度 Comate 与华为 CodeArts，这里不逐一展开。

  • 明确可私有化 / 数据不出域，人民币直购、合规沟通成本低。
  • 支持多模型切换（混元 / GLM / DeepSeek，含 Ollama 本地模型），不锁死模型，议价空间大。
  • 价格只有海外旗舰的零头：体验版免费（每月 500 积分），标准版 ¥99 / 高级版 ¥199 / 旗舰版 ¥999 每月，企业专享 ¥316/人/月（专有云）。
  • Agent 长任务能力通常比海外第一梯队晚半步。
  • 官网无"信创"字样，有信创要求的必须单独索取资质与适配清单，"支持私有化"不等于"信创合规"。

适合：合规优先、预算敏感、私有化刚需的团队。

自研与开源 Harness

自研 Harness · Cline · Roomote · Aider 等

自研 harness 的典型路线是"多模型可插拔 + 编排优先 + 本地优先"：分档沙箱（故障时默认只读）、审批无应答即拒绝、本地会话日志、凭据只存引用。开源侧 Cline（100+ 模型、企业版有 SSO 与 RBAC）、Roomote（云单租户或自托管 Docker，10 人内免费）、Aider（极简 CLI，自带 key）各占一个生态位。

  • 模型随便换，不锁厂商；数据、凭据、日志默认留在本地。
  • 可脚本化接进 CI，自由度最高；自研 harness 还能与 Claude Code / Codex 共享 hooks 配置。
  • 企业级集中管控、审计汇聚、凭据托管（OS 钥匙串 / KMS）要自己补建。
  • 文件沙箱是策略围栏，不是内核级隔离，高安全场景要加固。

适合：平台 / 效能团队；要"自选模型 + 强编排 + 本地留痕"的场景。

矩阵读法

没有一家是全能冠军。先锁定你必须具备的两三项（比如"私有化 + 审计 + MCP"），再看哪家满足，不要比总分。

07开放性与合规

"开放"可以指开发者扩展，也可以指企业合规，最好分开看。

维度一：开发者扩展性，agent 能不能长出你的业务能力

MCP是 AI 工具的"USB-C 接口"：任何系统按规范实现一个 MCP Server，agent 就能连接使用。总表八家全部支持 MCP，其中 Claude 系生态存量最大。Skills / 插件解决流程沉淀，且 Agent Skills 采用开放的 SKILL.md 格式（Anthropic 发起的开放标准），ZCode 等工具直接兼容同一格式，你沉淀的技能资产不绑定单一工具，换工具迁移成本低。BYOK解决不被锁死：Codex CLI 最彻底（开源 + 任意兼容端点）；ZCode 支持客户端内配多供应商，且 GLM Coding Plan 一份额度可在 20+ 工具间共享，等于"订阅模型、harness 随便挑"。

若只看这几个维度：代码开源，Codex CLI 最彻底；协议开放、模型可换、一份订阅跨工具，ZCode 更省事；生态存量，Claude 系最大。国产客户端在私有化和中文体验上补得很快，长任务能力通常仍晚半步。

维度二：企业合规，法务和安全团队能不能过

这部分经常比功能更早把选项筛掉：

  • 数据出境与服务可用性：OpenAI 与 Anthropic 目前均不向中国大陆直接提供服务，用 Claude Code / Codex 意味着海外主体、海外支付、网络方案，以及代码（提示词）跨境传输的合规评估。这不是技术问题，是公司代码要不要出境的立场问题，需要数据安全团队书面确认。
  • 国内主体方案：智谱（ZCode）与腾讯（CodeBuddy）均为国内主体、人民币结算、数据处理路径清晰；两者都有企业级方案可谈。
  • 供应商条款必查：训练用途（商业版通常"不训练"，免费档常有例外，白名单要写到"档位"）、留存期（Anthropic 商业版 30 天，零留存需单独启用）、审计能力（Copilot 日志 180 天且不含本地会话）、IP 责任（微软对 M365 Copilot 有条件赔偿，GitHub 明示用户自担，不得默认厂商兜底）。
  • 敏感场景：无论选哪家，密钥文件（.env 等）都应进 agent 的禁读清单，harness 的权限机制在这里从"加分项"变成"必选项"。

三个看价要点

① 额度口径不一样，别只看月费。GLM Coding Plan 是积分制（5 小时窗口 + 周额度双轨刷新，非高峰消耗按 50% 抵扣）；Claude / Codex 是"5 小时滚动窗口限速"；CodeBuddy 是月积分。横向只比月费意义有限，建议先用免费/体验额度跑自己的真实任务再定档。

② 隐性成本往往超过订阅价本身。海外工具的海外支付、账号管理、网络访问与合规评估，摊到人均通常不低于订阅费的 30%~50%；这部分在国内直连的工具上接近于零。

③ API 计费适合轻用，重度开发几乎总是订阅划算。agent 一个真实任务动辄消耗数十万 token，订阅制包量明显更优，"Coding Plan"这类产品形态就是为这出现的。官方用量基准供参考：约 $13 / 开发者 / 活跃日、$150~250 / 人 / 月，Agent 团队的 token 消耗可达普通会话的 7 倍，云端异步任务务必配"断路器"（时长 / token / 并发 / 花费上限）。

09结论与建议

标准、合规和价格都摆完了，可以做选择。

形态上，多数团队不必赌单一工具：IDE 补全加 CLI Agent 做日常，审查 Bot 挂全仓，云端异步只试点。一个客户端很难同时解决手速、吞吐和合规。

国内团队主力推荐：ZCode

按第 04 节八项标准，ZCode 都能给出可用答案：图形界面、原生中文、MCP / Skills / Hooks 齐备，SKILL.md 还是开放格式。一份 GLM Coding Plan 也能拿去驱动 Claude Code、Codex、OpenCode 等其他 harness，相当于先订阅模型、再换工具。国内主体、人民币直购；Lite 连续包季折合 ¥94.4/月（月付 ¥118），试错成本不高。

其他选手的位置：

  • Claude Code / Codex 作为对照组：有海外订阅条件且合规评估通过的团队，值得保留一两个席位做横向基准，模型强、生态成熟。而且 Codex CLI 开源可接任意端点，GLM Coding Plan 的额度也能驱动它，等于"用国内账单体验海外 harness"。
  • Cursor 作为一体化选项：治理项最全、上手快，适合中小团队快速铺开；但要清楚它的云端 Agent 上下文会出网。
  • Copilot 作为平台顺手选项：代码本来就在 GitHub 云上的团队，它的门禁与审计最省心。
  • 国产专门客户端作为合规底座：以 CodeBuddy 企业专享版的专有云交付为代表，是信创和私有化刚需的主路径。
  • 自研 / 开源自托管作为自由度天花板：平台团队想自己掌控推理来源和审计闭环时选它，代价是企业级治理自己建。

模型几个月就会换代，跑分冠军也会轮换。更值得投的是能跟着仓库走的资产：MCP 接口、团队 Skills、AGENTS.md。优先选协议开放、格式开放、模型可换的客户端，换发动机时才不会把沉淀丢掉。
