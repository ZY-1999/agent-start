# Checklist

代码的评审清单。用于 review，也用于需求完成后的自检。

- 需求对齐：改动真的解决了问题吗？有没有做多余的事？
- 正确性：边界、异常、并发、幂等、时区、精度。
- 安全性：输入校验、权限判断、注入、敏感数据、依赖风险。
- 可维护性：命名、抽象层级、重复代码、注释是否解释"为什么"。
- 测试：覆盖失败路径了吗？是不是只测 happy path？手工验证步骤能复现吗？
- 可观测性：日志、指标、追踪够定位线上问题吗？
- 性能：N+1、全表扫描、循环内 IO、无上限缓存。
- 兼容与迁移：老数据、老客户端、灰度与回滚。
- 干净的 diff：混入格式化/重排噪声了吗？
- 责任确认：我愿意为这段代码的线上表现负责吗？
- 是否符合规范，详情见 [`developer.md`](./developer.md)。
