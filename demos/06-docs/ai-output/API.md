## 1. 注册新用户

`POST /api/v1/users`

**请求体：**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| phone | string | 是 | 非空，11 位手机号 | 登录手机号，全局唯一 |
| nickname | string | 是 | 非空，≤64 字符 | 昵称 |
| birthday | string (yyyy-MM-dd) | 是 | 非空，早于当前日期 | 出生日期 |

**成功响应：** `201 Created`

```json
{ "id": 10086, "phone": "138****0000", "nickname": "张三", "birthday": "1990-01-01" }
```

**错误响应：**

| 状态码 | 场景 |
|--------|------|
| 400 | 参数校验失败（@Valid 注解规则） |
| 409 | 手机号已注册（DuplicatePhoneException，具体错误码**待补充**） |

## 4. 更新用户昵称

`PATCH /api/v1/users/{id}/nickname`

**参数：**

| 参数 | 位置 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | path | integer | 是 | 用户 ID |
| nickname | query | string | 是 | 新昵称 |

**成功响应：** `200 OK`，返回更新后的用户。

> ⚠️ 建议：昵称作为查询参数传输，中文和特殊字符需要 URL 编码，且无法携带长度校验注解——**建议演进为请求体 + @Valid**（文档中标注为接口改进建议）。

## 5. 注销用户（逻辑删除）

`DELETE /api/v1/users/{id}`

**成功响应：** `204 No Content`（无响应体）

**错误响应：** `404`（用户不存在）
