## 60 分钟分享的时间分配建议

```
00:00 - 08:00   第一章：是什么（定义 + 三个技术阶段 + 心智模型）
08:00 - 18:00   Demo 01 + Demo 02（脚手架 + 祖传代码，先建立直观感受）
18:00 - 26:00   第二章剩余场景讲解（结合 Demo 03 ~ 06 的 ai-output 快速过）
26:00 - 36:00   第三章：边界在哪（含现场安排的一次幻觉演示）
36:00 - 44:00   第四章：四项实践（Prompt 对比现场演示）
44:00 - 56:00   Demo 07 收尾：传统约 30 分钟 → AI 约 1 分钟（现场出题）
56:00 - 60:00   Q&A
```

> Demo 08 不占现场演示时长：讲第四章项目级实践（实践一的项目规则、实践五与实践六）时打开 `08-project-demo/AGENTS.md` 展示配置全貌，并作为听众会后的取用模板。

## 排练 Checklist

- [ ] 所有 Demo 至少完整跑一遍，确认 Prompt 在你使用的模型上效果达标
- [ ] 每个 Demo 的 `ai-output/` 保底材料已检查（现场断网时直接展示）
- [ ] 准备一段**你们项目的真实代码**（脱敏后）替换至少一个 Demo 的输入——真实代码的说服力远高于玩具代码
- [ ] 演示环境提前准备好：模型页面登录态、字体调大、屏幕共享清晰度测试
- [ ] 演练一次"失误预案"：故意让模型生成错误答案，练习如何自然地引到第三章的边界讨论
- [ ] Demo 07 的日志文件提前生成大一点的版本（万行级），现场跑命令对比更明显

## 通用失误预案

| 意外情况 | 应对 |
|----------|------|
| 模型答错 / 编造 API | 正好现场教学："这就是第三章要讲的幻觉问题" |
| 网络故障 | 直接展示 `ai-output/` 目录，讲解 Prompt 与产出的对应关系 |
| 生成太慢 | 讲解 Prompt 的写法要点，边等边聊 |
| 观众质疑"我们项目这么复杂它能懂？" | 承认上下文限制（第三章边界二），邀请他散会后拿真实代码来试 |
